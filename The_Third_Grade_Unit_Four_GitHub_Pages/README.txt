THE THIRD GRADE — UNIT FOUR | GitHub Pages upload bundle

Files in this folder belong together. Upload ALL files from this folder to the ROOT of your GitHub repository (not into another folder, and do not upload the ZIP file itself).

Required contents include index.html, sw.js, manifest.webmanifest, icons, the exact original poster, and ten picture crops taken directly from that poster.

GitHub Pages setup:
1. Open the repository -> Settings -> Pages.
2. Build and deployment: Deploy from a branch.
3. Branch: main; Folder: / (root); Save.
4. Wait until GitHub Pages reports it has deployed, then open the Pages URL.
5. Visit the site once while online. Wait for “Offline support is ready on this device ✓”. Then Add to Home Screen on iPhone (Safari) or Install app on Android (Chrome). Test offline after the first visit/cache completes.

Game answers, in order: big, small, 4, 2, no, grey, brown, fast, slow, fast.
The poster file is copied directly from the user-provided image and is not edited.
